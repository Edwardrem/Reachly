### New

- **Servers you already use.** The sidebar lists the servers in `~/.ssh/known_hosts` under **Detected on this Mac**. **Add** saves one as a host and keeps its known host key; **Hide** takes it off the list.
- **AI providers found on this Mac.** Settings › AI Integration lists what is already installed: the Caimex CLI, Claude Code, Claude Desktop, Qoder, LM Studio and Ollama, plus `ANTHROPIC_API_KEY` or `OPENAI_API_KEY` in Reachly's environment. Each comes with one button, and a confirmation says exactly what will happen before anything is copied or changed. On first launch, when no provider is set up yet, a setup sheet shows the same list.
- **API keys.** Each provider has a **Get a key** link to its key page, the key field has a show/hide toggle, and a saved key shows as a masked preview such as `sk-ant-…a1b2`.
- **Qoder in the chat panel.** With the Qoder CLI installed, choose **Qoder (ACP)** or click **Use in Chat Panel** on the Qoder row. Qoder signs in with its own account, and Reachly never reads it. Commands on your servers go through Reachly's guardrails, approval sheet and audit log.
- **Comment instead of running.** The approval sheet has a **Comment** field. Send a comment and the model revises the command before anything runs.
- **AI History** (⌥⌘Y). A sidebar mode next to Snippets and History lists every command the assistant ran or proposed, from the chat panel and from MCP clients, with the decision, host, exit status and output. You can run a command again, save it as a snippet, or open its conversation.
- **Files window.**
  - **Commands:** Reload now refreshes, and New File…, Duplicate, Move to…, and Copy, Cut and Paste work within a side or between the Mac and a host, or between two hosts.
  - **Files menu:** while the Files window is in front, it holds Reload ⌘R, New File… ⌥⌘N, New Folder… ⇧⌘N, Duplicate ⌘D, Move to… and Delete… ⌘⌫. None of these keys ever acts on the main window.
  - **Folders on the Mac** refresh by themselves, and every Delete asks first.
- **Chat panel.** The transcript follows the reply while the model is thinking or typing. A request that fails stays in the conversation with **Retry**, so nothing you wrote is lost.

### Safer

- **Nothing is overwritten.** A name that is already taken gets a copy name or an error, and a file that appears while a paste is queued stops that transfer.
- **Cut moves only what arrived.** Cut to the other side removes the originals only once everything has arrived in full, and only files that are unchanged since the paste. On the Mac, what is removed goes to the Trash.
- **Transfers stay in their folder.** A file name sent by a server can't make a transfer write outside the folder you chose.
- **No SFTP on the server.** The Files window says so within seconds instead of waiting.
- **Keys stay with their endpoint.** A key for an OpenAI-compatible endpoint is sent only to the server it was saved for, and chat requests never follow a redirect to another server.
- **Cancelled requests close their sheet.** When an MCP client cancels a request or disconnects, its approval sheet closes, and the bridge never sends the same command twice.

### Updating from 1.0.1

- **With Homebrew:** `brew upgrade --cask reachly`.
- **Without Homebrew:** quit Reachly, replace it in Applications, and open it.

Your hosts, chats and settings stay where they are. Because builds are ad hoc signed, allow the new version once with Open Anyway, and click Always Allow when macOS asks for Keychain access to each saved password or key.

### Known limits

- **Signing:** the build is ad hoc signed, not notarized, so updates are download-only.
- **Qoder:**
  - It needs the Qoder CLI. The Qoder app alone isn't enough.
  - It has been tested against a scripted stand-in agent, not the real CLI.
  - Reachly starts it in Qoder's `default` permission mode, which replaces any stricter mode set in Qoder.
- **Going back to 1.0.1:** conversations that include a failed request open empty in 1.0.1.
- **Wording:** the empty panel and the Show Claude Panel menu item still say Claude whatever the provider.
- **Keys:** RSA keys can't be used to connect yet, and agent forwarding and FIDO2 keys are not supported.
