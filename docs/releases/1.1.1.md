### Fixed

- **Long chats no longer go blank.** In a long conversation the chat panel could lose its messages and show nothing until you scrolled. It happened most often while an approval sheet was open, which is exactly when you need to read what led up to the command. The transcript now lays out every message, so it always shows the conversation and its end. The reply coming in redraws at most ten times a second, so long conversations stay responsive while it streams.

### New

- **Caimex models that can run commands.** Settings › AI Integration now reads the tags, prices and hosting details the CAIMEx gateway publishes for each model. The Model menu lists only the models CAIMEx marks as able to call tools, which the agent needs to run commands. Under the menu you see the chosen model's context length, its price per million input and output tokens, the country it is hosted in, and whether CAIMEx may use what you send for training. A saved model that can't call tools stays selected and shows a warning. If the gateway sends no tags, every model is listed, as before.
