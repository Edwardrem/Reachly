The **Claude** tab in Settings is now called **AI Integration**. It sets up every provider (Anthropic, Caimex or any OpenAI-compatible endpoint) and the MCP server, not only Claude. Help text and error messages that sent you to Settings › Claude now point to Settings › AI Integration.

### Updating from 1.0.0

- Quit Reachly, replace it in Applications with the new version, and open it. Your hosts, chats and settings stay where they are.
- Because builds are ad hoc signed, macOS asks again for Keychain access the first time 1.0.1 opens each saved password or key. Click Always Allow.

### Known limits

- The build is ad hoc signed, not notarized. On first launch, allow it with Open Anyway in System Settings › Privacy & Security. Updates are download-only for the same reason.
- RSA keys can be generated, imported and pushed but not used to connect, because SwiftNIO SSH has no RSA signing. Agent forwarding and FIDO2 keys are not supported yet.
- The panel's title and the Show Claude Panel menu item say Claude whatever the provider.
- The agent needs a model with tool calling. The Caimex model list does not say which models have it, so pick one that supports tools.
