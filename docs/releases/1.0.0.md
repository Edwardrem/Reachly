**Reachly: every machine within reach.** Reach any machine from one place.

### What's in it

- **An AI assistant that works on your machines.** Claude, Caimex or any OpenAI-compatible endpoint can list your hosts, run commands over SSH, read and write files, move files between machines, read the terminal, and write reports as PDF, Word, HTML, Markdown, text or CSV. Each provider keeps its own key in the Keychain, and a key is only ever sent to its own provider. The chat names the provider that answers.
- **You stay in control.** Each host is read-only, ask every time, or allowlist. Destructive commands such as `rm -rf`, `dd`, `mkfs`, `DROP` or `shutdown` always ask first, in a sheet that shows the exact command, the host and the reason, with Approve, Edit and Deny. Terminal output reaches the model marked as untrusted data, and an audit log records every command with its host, time, decision and exit status.
- **Bring files and questions in any form.** Attach images, PDFs, Word documents, logs, configs or a whole folder. Hidden files, symbolic links and anything that looks like a key or password stay on your Mac. Dictate a question instead of typing it; speech is transcribed on the Mac.
- **A complete terminal.** Tabs and nested splits, true colour, 100 000 lines of scrollback, auto-reconnect after sleep, snippets with placeholders, a searchable history with exit codes, and inline suggestions.
- **Every way in.** Chained jump hosts, HTTP CONNECT and SOCKS5 proxies, local, remote and dynamic port forwarding, a dual-pane SFTP browser with a transfer queue, and serial consoles for routers, switches and boards.
- **Your fleet, organised.** Groups as projects with defaults that hosts inherit, drag and drop, tags and colours, and imports from `~/.ssh/config`, Termius, PuTTY, Tabby, AWS, DigitalOcean and Azure.
- **Private by design.** No account and no sync server. Hosts live in a local database, keys and passwords in the Keychain behind Touch ID, and one encrypted `.reachly` file moves everything to another Mac.
- **Works with other AI apps.** A built-in MCP server gives Claude Desktop, Claude Code and other MCP clients the same tools, guardrails and audit log.
- **Make it yours.** Bundled colour schemes and a theme editor that imports iTerm2, Windows Terminal, VS Code, Alacritty and Ghostty themes. The scheme colours the whole app, in light or dark.

### Known limits

- The build is ad hoc signed, not notarized. On first launch, allow it with Open Anyway in System Settings › Privacy & Security.
- Because builds are ad hoc signed, macOS asks for Keychain access the first time each new build opens a saved secret, and for the microphone and speech recognition the first time you dictate.
- RSA keys can be generated, imported and pushed but not used to connect, because SwiftNIO SSH has no RSA signing. Agent forwarding and FIDO2 keys are not supported yet.
- The panel's title, the Show Claude Panel menu item and Settings → Claude say Claude whatever the provider.
- The agent needs a model with tool calling. The Caimex model list does not say which models have it, so pick one that supports tools.
