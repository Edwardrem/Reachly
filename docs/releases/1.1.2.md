### Safer

- **Server text can't pose as instructions.** Command output, file contents and the terminal buffer reach the model wrapped as untrusted data. A wrapper tag inside that text is now escaped, so a log line can no longer pretend the output has ended and continue as if it were someone giving orders.
- **Adversarial tests.** A new prompt-injection test suite attacks both layers:
  - text that tries to close its wrapper;
  - a model that obeys an injected order anyway. On an allowlist host the destructive command still stops for a person and never runs. On a read-only host, commands and file writes are refused without asking. Every decision is audited.

### Tests and CI

- The test `sshd` on the CI runner now has to accept a login before the live tests start.
- A failed live run prints `sshd`'s log, and the retry runs one test at a time.
- An MCP server test now waits for a dropped connection's audit record instead of racing it.
